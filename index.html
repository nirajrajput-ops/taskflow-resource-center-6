What is TaskFlow?

TaskFlow is a fully client-side task management application built with React, TypeScript, and Tailwind CSS. Unlike most task managers, TaskFlow includes a built-in AI assistant that understands natural language commands — no cloud API, no subscription, no sign-up.

All your data lives in your browser's localStorage. Nothing is sent to any server. The AI runs entirely locally using a custom NLP parser and intent executor built into the app.

  • Conversational AI — create, update, complete, and query tasks by typing plain English
  • Multi-thread conversations — separate AI contexts for Work, Personal, and more
  • Full CRUD — tasks with subtasks, priorities, due dates, times, and reminders
  • Color-coded categories — 5 built-in plus unlimited custom ones
  • Live dashboard — real-time stats across all your tasks
  • Zero backend — 100% private, runs in any modern browser
💡
Pro tip
The fastest way to learn TaskFlow is to open the AI assistant and type help. It will show you everything it can do.

How the AI works.

TaskFlow's AI runs entirely in your browser — no API calls, no cloud, no latency. Here's what's happening under the hood.

Architecture

The AI system has two distinct layers:

1. Parser — src/agent/parser.ts
Converts your plain-English input into a structured command object: intent type, task title, priority, due date, category, reminder interval, and any referenced entities. Uses regex-based pattern matching and keyword detection with multi-pass entity extraction.
2. Executor — src/agent/executor.ts
Takes the command object and executes it against your live task context. Handles 15+ intent types. Supports fuzzy matching (exact → starts-with → contains) for task and category lookups. Updates state via React context and returns a formatted response.

Multi-Thread Conversations

The AI supports multiple named conversation threads. Each thread maintains its own context independently — so what you're discussing in your "Work" thread doesn't bleed into your "Personal" thread.

  • Click + New thread to create a separate conversation context
  • Rename threads by clicking on the thread name
  • Switch threads without losing context in either
  • Delete threads to clear their conversation history
  • Thread conversations persist across page refreshes via localStorage
ℹ️
Note
Context references like "it" or "the first one" only work within the same thread. Switching threads resets what the AI considers the "last mentioned" task.

// context memory

The AI remembers.

Within a conversation thread, the AI tracks what you just talked about — so follow-up commands feel natural.

What the AI Tracks

  • Last mentioned task — referenced by "it", "that task", "this one"
  • Last listed tasks — referenced by "#1", "#2", "the first one", "the second task"
  • Last created task — referenced immediately after creation
  • Active category filter — remembered for follow-up queries

Context Reference Examples

ReferenceWhat it resolves to
itThe last task mentioned or created
that taskSame as "it"
this oneSame as "it"
#1, #2Position in the last listed tasks
the first onePosition 1 in the last listed tasks
the second taskPosition 2 in the last listed tasks
the last oneLast item in the last listed tasks

Context in Practice

conversation 
You:  Show all overdue tasks
  ↳  [Lists: 1. Review PRs, 2. Update roadmap, 3. Pay invoice]

You:  Complete #2
  ↳  ✓ Marked "Update roadmap" as complete

You:  Change priority of #1 to high
  ↳  ✓ Updated "Review PRs" priority to High

You:  Add task "Follow up on #3"  ← NOTE: #3 here is text, not a reference
  ↳  ✓ Created "Follow up on #3"

You:  Delete it
  ↳  ✓ Deleted "Follow up on #3" (the last created task)
⚠️
Context resets on thread switch
When you switch to a different conversation thread, the positional context resets. "#1" in a new thread has no meaning until you run a list command.

Filtering & Sorting

On the Tasks page, use the filter chips to narrow by status, and the sort dropdown to order by:

  • Due date — earliest first
  • Priority — high → medium → low
  • Created date — newest first
  • Title — alphabetical

Combine a filter chip (e.g., Pending) with a sort (e.g., Priority) to quickly surface what matters most.

Never miss a deadline.

Set reminders on tasks and TaskFlow will notify you before the due time arrives.

How Reminders Work

Reminders use the browser's built-in notification system. When a task's reminder time passes, a toast notification appears in the bottom corner. The app periodically checks for due reminders while it's open in your browser.

ℹ️
Browser must be open
Since TaskFlow is a client-side app with no background service, reminders only fire when the app tab is open and active.

Available Intervals

  • 15 minutes before — good for meetings and tight deadlines
  • 1 hour before — preparation reminders
  • 1 day before — planning ahead for tomorrow's tasks

Setting a Reminder

Via AI

AI commands
Add task "Doctor appointment" due tomorrow at 3pm remind me 1 hour before
Add task "Submit expenses" due Friday remind me 1 day before

Via the UI

When creating or editing a task, find the Reminder dropdown in the task form. Select your preferred interval. The field is only active when a due date is set.

Overdue Notifications

Even without an explicit reminder, TaskFlow tracks overdue tasks. Any pending task whose due date has passed appears highlighted in red on the Tasks page, and counted in the Dashboard's Overdue stat card.

Frequently asked questions.

Quick answers to the most common questions about TaskFlow.

Is my data private? Does it go to a server?▾
Completely private. TaskFlow stores everything in your browser's localStorage. No data is ever sent to any server — there isn't one. Your tasks stay on your device and are only visible to you.
What happens if I clear my browser data?▾
All your tasks, categories, and AI conversation threads will be lost, as they are stored in localStorage. There is no cloud backup. If you need to preserve your data, consider exporting it before clearing browser storage.
Does the AI use ChatGPT or any external AI service?▾
No. TaskFlow's AI assistant is a custom-built NLP engine that runs entirely in your browser. It uses regex-based pattern matching and keyword intent detection — no API calls, no external dependencies, no network required after the initial page load.
Can I use TaskFlow offline?▾
Yes, once the app has loaded. Since everything runs client-side and data is stored in localStorage, TaskFlow is fully functional without an internet connection. The only thing that requires a connection is the initial app load (fetching JS/CSS bundles) and loading Google Fonts.
The AI said "I didn't understand that." What should I do?▾
The parser works best with clear action words. Instead of questions like "Can you maybe add…", try direct commands: "Add task…". You can also type help to see all supported command patterns. If a specific phrasing consistently fails, try a synonym — "create" works as well as "add".
Can I access TaskFlow from multiple devices?▾
Not in the current version. Since data is stored in each browser's localStorage, your tasks on one device are not visible on another. Each browser instance maintains its own separate task database.
How do I recover a task I accidentally deleted?▾
Unfortunately, deleted tasks cannot be recovered. There is no trash or undo history. Deletion is permanent. Always confirm task names before issuing a delete command to the AI.
Can the AI create multiple tasks at once?▾
The current parser handles one intent per message. To create multiple tasks, send separate commands — one per message. Each command is processed independently, and the AI will confirm each creation.
How do I add a task with a long description?▾
The AI's CREATE_TASK command focuses on the task title, priority, date, and category. For tasks that need a long description, create the task via AI first, then click into the task from the Tasks page and edit the description field directly in the Task Form.
Is there a keyboard shortcut to open the AI chat?▾
In the current version, the AI assistant is opened by clicking the floating ⚡ button in the bottom-right corner of the screen. Keyboard shortcuts for the AI panel are on the feature roadmap.

Something not working?

Common issues and how to resolve them.

AI Assistant Issues

AI doesn't respond

Make sure the chat panel is fully open and you're pressing Enter or clicking the send button. If the input field appears frozen, try refreshing the page — conversation history is preserved in localStorage.

AI creates the wrong task

The parser extracts the task title from everything between quotes or after the action keyword. Wrapping titles in quotes gives the most reliable results:

recommended
Add task "Buy fresh coffee beans" due tomorrow    ← quoted title
less reliable
Add task Buy fresh coffee beans due tomorrow      ← ambiguous

Date not parsed correctly

Some ambiguous phrases may not resolve as expected. Use ISO format (2026-05-28) for guaranteed accuracy, or check the Date Parsing reference.

Data Issues

Tasks disappeared after browser update

Some browser updates or privacy settings clear localStorage. Check your browser's site data settings for localhost. If the data is gone, it cannot be recovered — this is a known limitation of localStorage-only persistence.

App looks broken or styles are missing

This usually means the Vite dev server isn't running, or the built assets aren't being served correctly. Ensure npm run dev (development) or npm run build && npm run preview (production) is running.

🚫
Opening index.html directly won't work
TaskFlow uses ES modules and a Vite dev server. You cannot open index.html directly as a file:// URL — it must be served via npm run dev.

Reset & Clear Data

To fully reset TaskFlow, open your browser's DevTools (F12), go to Application → Storage → Local Storage → localhost, and delete the following keys:

localStorage keys
todo_app_tasks
todo_app_categories
todo_app_notifications

After deleting these, refresh the page. TaskFlow will reinitialize with the 5 default categories and no tasks.
